# House Price Prediction

A Machine Learning project that predicts house prices using Supervised and Unsupervised Learning.

## 📁 Project Structure

## 🎯 Supervised Learning

Algorithm: Linear Regression  
Goal: Predict House Price based on Size

Results:
- MSE: 3.03
- R2 Score: 0.999 (99.9% Accuracy)
- Graph: Blue dots = Real prices, Red line = Predicted
